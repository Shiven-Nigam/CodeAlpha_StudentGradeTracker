# 🎓 Student Grade Tracker

A simple Java console-based application developed as part of the **CodeAlpha Java Programming Internship**.

The Student Grade Tracker allows users to enter and manage student information and marks, calculate average scores, determine grades, and generate a summary of student performance.

---

## 📌 Project Overview

The main purpose of this project is to demonstrate the use of Core Java and Object-Oriented Programming concepts by building a practical student grade management application.

The application can:

- Add student details
- Store student marks
- Calculate average marks
- Find highest marks
- Find lowest marks
- Calculate student grades
- Display student results
- Generate a summary report

---

## ✨ Features

### 👨‍🎓 Student Management

- Add student name and marks
- Store multiple student records
- Display all student records
- Search/view student information

### 📊 Grade Calculation

The application automatically calculates:

- Total marks
- Average marks
- Grade
- Highest marks
- Lowest marks

### 📋 Summary Report

The application displays a summary containing:

- Number of students
- Average class marks
- Highest score
- Lowest score
- Individual student grades
